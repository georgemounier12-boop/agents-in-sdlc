Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software mediante situaciones realistas, una aplicación completa y una lista de tareas compartida. Trabajarás de forma iterativa para planificar cambios, crear código, probar el comportamiento, revisar solicitudes de cambios y administrar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con un tema de desarrollo. Las tareas pendientes del equipo ya están registradas como incidencias de GitHub, listas para que empieces a trabajar. Incluyen funcionalidades como el filtrado y la paginación, además de mejoras de calidad, como la accesibilidad y los estándares de programación.

## Elige tu entorno

GitHub Copilot está disponible en los entornos que usas para trabajar. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller empieza con su propia configuración y usa el mismo escenario de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes desde el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia entre modos de sesión, colabora con lienzos y administra incidencias y solicitudes de cambios de GitHub desde la aplicación de escritorio.

### [Agente en la nube de GitHub Copilot][cloud]

Asigna incidencias de GitHub a un agente asíncrono, orienta su trabajo, supervisa el progreso y revisa las solicitudes de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo Agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
